# Godot Package Import Harness

This directory documents the minimal Godot import harness generated by
`tests/tools/verify_engine_package_import.py`.

CI uses the generated project to verify that the shipped Godot addon artifact is
self-contained under `addons/imm_viewer`, declares the supported platform
libraries in `imm_viewer.gdextension`, and can be copied into a clean Godot
project layout before runtime smoke tests run on hardware lanes.
