# Web decoder baselines

`sample1-native-decoder.json` is a compact conformance manifest generated by the
native `ImmStrokeReader` plugin. It records hashes and counts instead of storing
all decoded point data.

Regenerate it from the repository root after intentionally changing native IMM
decoding behavior:

```powershell
python tests/tools/generate_native_web_manifest.py
```

The generator writes its native log to `artifacts/web-native-manifest.log`.
Review manifest changes before committing them; a new plugin build ID alone is
not a reason to accept changed decoded hashes.
